Boostcamp alternative

Looking for a Boostcamp alternative? Log every set offline with IronBuddy

As a Boostcamp alternative, IronBuddy is built for logging at the gym: reps and weight for every set, set techniques like drop sets and supersets, and notes, on your Android phone with no connection, no account, no ads and no subscription.

How IronBuddy logs your sets

Open a training day from the home screen with its Log button, or log a single exercise from its preview. Every set gets its own reps and weight.

  • Quick + and − buttons: reps step by 1 and weight by 2.5 kg or 5 lb. On an empty field, + starts from the previous set's value. You can still type any number.
  • Sets control: + copies your last set and − removes it, so adding a set takes one tap.
  • Set techniques: add a drop set, rest-pause, myo-rep, cluster set, back-off set, mechanical drop, pyramid or superset to any set.
  • Notes: add a note to any exercise, and a note for the whole day of up to 500 characters.
  • Quick log: log one exercise into your history without editing the whole day.
  • Any date: log a workout for today or fill in a past date.

Logging drop sets and supersets so they stay comparable

  • Log the working set first. Its weight and reps are the numbers to compare week to week. IronBuddy attaches a technique to the working set and uses the working set for your 1RM (one-rep max), calculated with the Epley formula, so the extra reps from a drop or rest-pause do not inflate it.
  • Use each technique the same way every time. If a drop set means one strip of about 20%, keep it that way, so the sessions line up.
  • Supersets: log each exercise's own sets, and add the Superset technique to a set to mark it as done back-to-back with the next exercise. Each exercise keeps its own history.
  • Write down what changed. A new grip, a slower tempo or a sore joint explains a number that looks odd a month later.

Switching from Boostcamp to IronBuddy

  1. Export your Boostcamp history first if the app offers an export, and keep the file as an archive.
  2. Write down the program you follow now: the days, the exercises, and the sets and reps for each.
  3. In IronBuddy, pick the built-in split closest to your program and edit its days to match.
  4. Log your first session set by set, adding drop sets or supersets where your program uses them.

Questions about switching from Boostcamp

Is IronBuddy affiliated with Boostcamp?

No. Boostcamp is a trademark of its owner, and IronBuddy has no affiliation with it. The name is used here only to describe what people search for.

Can I import my Boostcamp workout history into IronBuddy?

No. IronBuddy restores only its own backup files, so history from other apps cannot be imported. Start a fresh log with your current working weights and log each set as you go; your history builds from the first session.

Can I log drop sets and supersets in IronBuddy?

Yes. You can add a drop set, rest-pause, myo-rep, cluster set, back-off set, mechanical drop, pyramid or superset to any set. IronBuddy keeps the working set's weight and reps as the numbers it uses for your 1RM.
