Rest-pause sets, drop sets and supersets: how to do and log them

Drop sets, supersets and rest-pause sets are ways of getting more work out of a set than one straight set gives you. Used on the right exercises, at the right time, they save minutes and add hard reps. Used everywhere, they wreck your recovery and your log. This guide explains each one, when it helps, and how to record it so your numbers still mean something.

Last updated 21 October 2026

Key takeaways

  • A drop set extends a set by lowering the weight; a superset pairs two exercises; rest-pause splits a set with short pauses.
  • They add hard reps in less time, not more muscle per hard rep. Use them for time and intensity, on machines and isolation work.
  • Keep them to the last set of an exercise, one or two exercises a session, and not every week.
  • Log every drop, pause chunk and paired exercise with its own reps and weight, so your volume and sets per muscle are right.

Drop sets

A drop set is a set that does not end when you fail. You finish your reps, take 20 to 30 percent off the weight at once, and keep going until you are close to failure again. One drop is the usual version; two is a lot; three is a party trick. The point is that the muscle keeps working past the point where the original weight stopped it.

  • Where: machines, cables and dumbbells, where changing the weight takes a second and a sloppy last rep is harmless. Lateral raises, curls, pushdowns, leg extensions, pec deck.
  • When: the last set of an exercise. Doing it on every set means the later sets are done exhausted, and the quality drops.
  • Logging: the main set as normal, then each drop as its own row with the lower weight and the reps you got. Both count toward your volume, because both were work.

Supersets

A superset is two exercises done back to back, then a rest. The common versions pair opposite muscles (a curl and a pushdown, a row and a press), or two exercises for the same muscle (a fly straight into a press). Opposite-muscle supersets cost you almost nothing in performance and halve your rest time; same-muscle supersets are a way to pile fatigue onto one area.

  • Where: arms, shoulders and any session where you are short of time. Two stations next to each other help; a busy gym does not.
  • When: whenever. Opposite-muscle supersets are the one technique you can run every week without much cost. The Arnold split pairs biceps and triceps this way.
  • Logging: each exercise with its own sets, reps and weight, plus a note that they were paired. The pairing matters when you compare with last time: 10 curls straight after 10 pushdowns is not the same as 10 fresh curls.

Rest-pause sets

Rest-pause takes one heavy set and stretches it with short breaks. Do your reps to a rep or two from failure, rack the weight, rest 10 to 20 seconds, and do as many more as you can with the same weight. Repeat once or twice. Something like 10, then 4, then 3 is typical. You end up with 17 reps at a weight you could only do 10 straight, in about a minute more.

  • Where: machines and dumbbells. Anything where you can set the weight down safely and pick it up again without a spotter.
  • When: the last set of a main exercise on a day you have energy. It is the most demanding of the three.
  • Logging: the first set, then each pause chunk with its reps. Same weight every time, so if the weight changes it was a drop set, not rest-pause.

Five more worth knowing

  • Pyramid

    Weight up and reps down from set to set (or the reverse). Each step is a normal set.

  • Back-off set

    A lighter set after your heaviest work, usually for more reps. Log it at its own weight.

  • Myo-reps

    An activation set of 12–20, then several mini-sets of 3–5 with a few breaths' rest. Each mini-set is logged.

  • Cluster set

    One set broken into clusters of 2–3 reps with 10–20 seconds between, so you can use a heavier weight.

  • Mechanical drop

    When you cannot do another rep, switch to an easier variation (incline push-up after push-ups) with the same weight.

Four rules that keep them useful

  1. Last set only. Everything before it is straight sets at full quality.
  2. Isolation and machines, not heavy compounds. Squats, deadlifts and barbell presses stay straight; fatigue is when form goes.
  3. One or two exercises per session. More than that and tomorrow's session pays for it.
  4. Log the whole thing. Reps and weight for every drop, chunk and paired exercise. A drop set logged as “one set” makes your volume look lower than it was and your progress look flatter than it is.

Questions about set techniques

Do drop sets build more muscle than straight sets?

Not for the same number of hard sets, as far as the research goes: when volume and effort are matched, drop sets and straight sets grow muscle about the same. What drop sets do is pack more hard work into less time. Use them for that, not because they are magic.

How often should I use these techniques?

On the last set of an exercise, on one or two exercises per session, and not every week. They are tiring, and the fatigue carries into the next day. IronBuddy's presets suggest them as optional extras (a drop set on the last set now and then, biceps and triceps as supersets now and then) for exactly that reason.

Can I do drop sets on squats or deadlifts?

You can, but it is a poor trade. Form on heavy compounds goes first when you are exhausted, and that is when drop sets happen. Keep squats, deadlifts and presses as straight sets and save the techniques for machines, cables and dumbbells, where a sloppy last rep costs nothing.

A note on safety

This guide is general training information, not medical advice. Techniques that take a set past failure are demanding; use them with weights you can set down safely, and speak to a qualified professional if you have an injury or a health condition.
